# Slice contract

Each simulation slice records its selected implementation pack, runtime target, architecture mode, discovery scope, use-case contract, business rules, ports, deterministic scenario, tests, done criteria, and exclusions. Slice documents refine the one shared simulation environment rather than creating separate applications.

Current slices: [`01-demand-signal.md`](01-demand-signal.md), [`02-visitor-writes.md`](02-visitor-writes.md), and [`03-admin-writes.md`](03-admin-writes.md).
