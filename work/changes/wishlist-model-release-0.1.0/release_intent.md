# Model release intent: Wishlist 0.1.0

Accept a bounded domain model for WNT Wishlist covering public apps and feature views, app filtering, verified identities, votes, private suggestions and moderation, and admin-controlled feature lifecycle. Release only the behavioral model and the executable anonymous public board read contract. The first technology synchronization target is a Go API plus SolidJS web app, beginning with anonymous public board reads.

The product remains a demand signal: ranking never commits WNT to build a feature. This release is not a production application or a deployment authorization.
